# Muons through the full cosmic stand

Open **cosmic_rate_report.pdf** for the result and figures. This report compares
no overhead roof with the requested 3 ft of concrete. The estimates are about
1.4 and 1.2 muons/hour, respectively, for a straight trajectory crossing all 26
active layers. They include approximate continuous energy loss, but no detector
efficiency, scattering, stochastic losses or decay.

## Rebuild

Use Python 3.10 or newer, ROOT with GDML support, and Tectonic. From this folder:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
./build_report.sh
```

Alternatively, compile the existing LaTeX and figures without recalculating:

```sh
tectonic -X compile cosmic_rate_report.tex
```

The supplied geometry and source range tables make the numerical calculation
independent of the original checkout. No network is needed for the calculation;
Tectonic may download LaTeX packages during its first compilation.

## Files

- `cosmic_rate_report.tex` and `.pdf`: report source and compiled report.
- `geometry_acceptance.*` and `rate_comparison.*`: vector PDF and PNG figures.
- `calculate_rate.py`: finite-volume coincidence integral; `results.json` records it.
- `check_rays.C`: an independent check using ROOT's original GDML solids.
- `root_ray_check.json`: 192 rays, 4,992 layer decisions, zero disagreements.
- `shielding.py`: energy-spectrum and range calculation; results in `shielding_results.json`.
- `material_chords.csv`: detector path lengths from ROOT for 96 accepted trajectories.
- `layer_inventory.json`: all 26 active layers, their footprints and positions.
- `geometry/`: the GDML, numerical scene and provenance snapshot used here.
- `sources/`: PDG concrete and polystyrene muon range tables.
- `make_report.py`: generates the plots and LaTeX from the numerical results.
- `SHA256SUMS`: artifact hashes, generated by `manifest.py`.

The 104 HCal bars remain an inferred layout. The ECal, tracker, trigger and LYSO
internals are the ESA GDML implementations placed in the STEP-derived frame.
This calculation does not validate their survey alignment. The shielding model
assumes ordinary concrete at 2.30 g/cm³ covering every accepted direction.

The incident spectrum is Guan et al. (arXiv:1509.06176), normalized to the PDG
sea-level vertical intensity above 1 GeV/c. The report identifies the additional
low-energy and detector-material approximations. Cite the report's references
if reusing the model; its numerical precision is not a physical error estimate.

## Raising the assembly and centering ECal

The added report page compares the original layout with two variations:

- Raise all three TS stations, all four tracker sensors and both LYSO layers by
  200 mm. Keep HCal and ECal fixed. The estimated rate falls by 10.2%, to
  1.264 muons/hour without a roof or 1.077 with 3 ft of concrete.
- Also center the complete ECal active-silicon envelope on the LYSO/TS axis.
  This is a +46.56 mm X and -46.08 mm Y shift, with no change in ECal height,
  rotations or internal layer offsets. The rates become 1.949 and 1.660
  muons/hour: 54.2% above raising alone, or 38.5% above the original layout.

`shift_up_200mm/` contains the raised numerical scene, integration results,
`comparison.json`, the ROOT intersection check and the three-layout figure.
Its `ecal_centered/` subfolder contains the raised-and-centered variant.
The stopping proxy stays at the original 32.70 g/cm² vertical detector column.
These are geometric placement studies, not mechanically validated or
transport-ready replacements for the original GDML. The original PDF and
source are retained in `shift_up_200mm/before_append/`.

The full rebuild includes both comparisons. To recompute only these additions
using the existing baseline results:

```sh
python shift_up_200mm/calculate_shift.py
python shift_up_200mm/calculate_shift.py --center-ecal
python shift_up_200mm/make_section.py
python make_report.py
tectonic -X compile cosmic_rate_report.tex
python manifest.py
```

## Centering ECal alone, or removing ECal

The final report page keeps TS, tracker, LYSO and HCal at their original
positions and tests two more layouts:

- **Center ECal only:** the same +46.56 mm X and -46.08 mm Y translation,
  with its height unchanged. Requiring all 26 layers gives 2.163 muons/hour
  without a roof or 1.842 with 3 ft of concrete.
- **Remove ECal:** omit its four active layers and its entire material subtree.
  Requiring the remaining 22 layers gives 2.214 or 1.883 muons/hour. ROOT
  chords reduce the detector mass-column proxy from 32.70 to 24.32 g/cm².

The no-ECal case means physical removal, not merely excluding ECal from a
trigger. Both retain the report's approximate sea-level spectrum and CSDA
stopping model, without scattering or detector efficiency.

`ecal_comparison/centered_only/` and `ecal_comparison/without_ecal/` hold the
scenes, rates, angular distributions, accepted rays, ROOT checks and material
chords. `ecal_comparison/all_layout_rates.pdf` compares all five layouts. The
four-page report preceding this addition is saved in
`ecal_comparison/before_append/`. To rebuild just the new cases:

```sh
python ecal_comparison/calculate_cases.py
python ecal_comparison/make_section.py
python make_report.py
tectonic -X compile cosmic_rate_report.tex
python manifest.py
```

The original calculation also accepts `--without-ecal` for a 22-layer
geometrical selection. Use the companion script above for the matching
material-removal and shielding calculation.
